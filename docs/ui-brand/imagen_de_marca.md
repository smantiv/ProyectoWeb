# Imagen de Marca

La aplicación mantendrá coherencia visual con la identidad del colegio **Santa Francisca Romana**, tomando como referencia los estilos tipográficos y la paleta de colores presentes en su sitio web oficial. El objetivo es que la aplicación se perciba como una extensión natural del ecosistema digital del colegio.

---

# Tipografía

La aplicación utilizará dos tipografías principales, consistentes con las usadas en la página web institucional.

### Montserrat

Se utilizará principalmente para **títulos y elementos de jerarquía visual**.

Uso en la app:

- Títulos de pantallas
- Encabezados de secciones
- Nombres de módulos
- Elementos de navegación importantes

Ejemplo:

- título de página
- nombre de sección
- tarjetas principales

Esta tipografía aporta un estilo **moderno, limpio y estructurado**, ideal para organizar la interfaz.

---

### Open Sans

Se utilizará para **contenido textual y elementos de lectura continua**.

Uso en la app:

- descripciones
- texto informativo
- contenido dentro de tarjetas
- labels de formularios
- botones secundarios

Esta tipografía fue elegida por su **alta legibilidad en pantallas**, especialmente en dispositivos móviles.

---

# Paleta de colores

La aplicación adoptará la paleta cromática identificada en el sitio web institucional.

## Colores principales

**Naranja institucional**

Color principal de interacción dentro de la aplicación.

RGB: **rgb(252, 99, 0)**

Uso en la app:

- botones principales
- llamadas a la acción
- elementos interactivos importantes
- indicadores activos

---

**Naranja acento**

Color utilizado para estados activos o interacción secundaria.

RGB: **rgb(233, 94, 43)**

Uso en la app:

- hover de botones
- elementos destacados
- estados activos

---

**Naranja claro**

Color de apoyo para feedback visual más suave.

RGB: **rgb(255, 160, 102)**

Uso en la app:

- estados secundarios
- highlights
- feedback visual suave

---

## Colores de navegación y enlaces

**Azul oscuro / gris azulado**

Color utilizado para enlaces y elementos de navegación.

RGB: **rgb(26, 46, 64)**

Uso en la app:

- enlaces
- navegación secundaria
- iconos de sistema

Este color aporta **contraste y estabilidad visual** frente al naranja institucional.

---

## Colores de texto

**Gris oscuro – Texto principal**

RGB: **rgba(0, 0, 0, 0.8)**

Uso:

- contenido principal
- textos largos
- formularios

---

**Gris medio – Texto secundario**

RGB: **rgb(87, 87, 86)**

Uso:

- subtítulos
- información secundaria
- metadatos

---

**Gris carbón – Títulos**

RGB: **rgb(32, 32, 32)**

Uso:

- títulos importantes
- encabezados de sección

---

## Colores de fondo

**Blanco – Fondo principal**

RGB: **rgb(255, 255, 255)**

Uso:

- fondo general de la aplicación
- contenedores principales

---

**Gris claro – Fondo secundario**

RGB: **rgb(240, 240, 240)**

Uso:

- secciones diferenciadas
- tarjetas
- bloques de contenido
