# Aclaración sobre los mockups

Los mockups del sistema fueron diseñados inicialmente utilizando **Figma** y generados mediante **Figma Make**, con el objetivo de acelerar la construcción de las interfaces y visualizar el diseño de interacción del sistema.

La implementación generada por esta herramienta utiliza tecnologías modernas de frontend:

- **React**
- **TypeScript (.tsx)**
- **JSX / TSX**
- **Tailwind CSS**
- **React Router**

En este contexto, las pantallas no corresponden a archivos HTML estáticos, sino a **componentes de React** que representan cada vista del sistema.

Los mockups pueden visualizarse en el siguiente enlace:

**https://stage-camp-98057067.figma.site**

Estas pantallas se utilizan **únicamente como representación visual del diseño del sistema**.

Para la implementación del proyecto se utilizarán las tecnologías vistas en el curso:

**Frontend**
- HTML
- CSS
- JavaScript (manipulación del DOM)

**Backend**
- Java
- Spring Boot

De esta forma, los mockups actuales sirven como **referencia de diseño**, mientras que la implementación final seguirá la arquitectura y tecnologías solicitadas en el proyecto.
