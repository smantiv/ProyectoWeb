# Alcance del CRUD — Entrega 1

Este documento describe el alcance de la implementación CRUD para la primera entrega del sistema de gestión de vigilancia escolar.

El objetivo es definir qué entidades del sistema tendrán operaciones CRUD implementadas en la aplicación MPA durante esta fase del proyecto.

---

# CRUD definidos para el sistema

Las operaciones CRUD completas del sistema se encuentran documentadas en el archivo:

**matriz_crud.pdf**

En ese documento se especifican las entidades del sistema, sus campos principales y las operaciones Create, Read, Update y Delete asociadas a cada una.

---

# Alcance de implementación para la Entrega 1

Aunque el diseño del sistema contempla múltiples entidades, para la primera entrega solo se implementarán las funcionalidades mínimas solicitadas en el enunciado del proyecto.

Las funcionalidades mínimas incluyen:

- Gestión de turnos
- Registro de incidentes
- Visualización de incidentes por zona (tabla tipo mapa de calor)
- Propuesta de reemplazo de vigilantes

---

# Entidades consideradas en la implementación inicial

Para soportar estas funcionalidades se implementarán los CRUD necesarios para las siguientes entidades principales:

- Usuarios
- Turnos
- Zonas
- Incidentes
- Solicitudes de reemplazo

Estas entidades permiten cubrir los procesos centrales del sistema requeridos para esta fase del proyecto.

---

# Entidades consideradas solo a nivel de diseño

Algunas entidades definidas en el modelo del sistema pueden quedar únicamente documentadas en esta etapa, pero no necesariamente implementadas completamente en la aplicación.

Estas entidades forman parte del diseño completo del sistema, pero su implementación podrá realizarse en etapas posteriores del proyecto.

---

# Objetivo del CRUD en esta etapa

La implementación CRUD en esta fase tiene como propósito:

- Validar el modelo de datos del sistema
- Permitir la interacción básica con las entidades principales
- Servir como base para la implementación de las funcionalidades principales del sistema en las siguientes entregas
