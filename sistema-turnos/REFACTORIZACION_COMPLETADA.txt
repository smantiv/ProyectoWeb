🚨 SOLUCIÓN DE PROBLEMAS COMUNES:

  ❌ "npm: command not found"
     → Node.js no está en PATH, reinstala desde https://nodejs.org

  ❌ "Module not found: axios"
     → Ejecuta npm install

  ❌ "Connection refused" en API
     → Spring Boot no está corriendo, ejecuta mvn spring-boot:run

  ❌ "Port 3000 already in use"
     → Otra instancia está corriendo, mata con npx kill-port 3000
